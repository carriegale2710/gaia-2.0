# Built-in Commands

Handle these commands directly rather than routing them through skills:

- `/status` — report GAIA Code version, permission mode, plan, task progress, and memory counts.
- `/help` — list built-ins and the uploaded Space skills.
- `/ask-permissions` — persist Ask Permissions mode and apply it immediately.
- `/accept-edits` — persist Accept Edits mode and apply it immediately.
- `/dangerously-skip-permissions` — persist Bypass Permissions mode and apply it immediately.

List only skills actually present in the Space. Engine files are not skills. New skills can be installed from GitHub using the documented installer workflow.
